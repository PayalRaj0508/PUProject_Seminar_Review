
## 1. Introduction

In postgraduate education, seminar projects play an important role in developing students’ research, analytical, technical, and presentation skills. Managing a large number of seminar groups, students, research topics, faculty guides, review marks, and related academic information manually can become time-consuming and difficult to maintain. As the number of student groups and faculty members increases, institutions require an organized and centralized system to manage seminar activities efficiently. To address these challenges, this project proposes a **Seminar Guide Allocation and Review Dashboard**, a web-based application designed to manage and monitor the complete seminar management process.

The proposed system provides a centralized platform for maintaining information related to **student groups, students, research topics, domains, project types, faculty guides, review marks, and company details**. The dashboard is integrated with Google Sheets, allowing academic data to be loaded from and saved to a centralized spreadsheet. The system also provides automatic synchronization and saving mechanisms to reduce the possibility of data loss and minimize repetitive manual data entry.

A major component of the system is the **Guide Allocation Module**, which assists in assigning seminar groups to faculty members. Faculty information includes their name, Ph.D. status, maximum group capacity, assigned groups, and remaining capacity. The system provides an **Auto Allocate** feature that can distribute groups among available faculty members based on defined capacity rules. It also supports options such as maintaining existing allocations, prioritizing Ph.D. faculty, applying a common faculty capacity, balancing capacities, and clearing assignments when required.

The **Groups and Students Module** provides a structured view of seminar groups and their associated students. Users can search and filter groups based on course, semester, domain, project type, guide, review status, and company availability. Each group can contain student information, research topic, domain, project type, guide, group email, company information, and company-letter details. New groups and students can also be added or existing records can be modified through the dashboard. The uploaded project also defines fields such as course, semester, research topic, domain, type, guide, company, and students as part of the group management interface.

Another important feature is the **Student-wise Review Module**, which enables faculty members to enter review marks for individual students. The system provides six review components, allowing marks to be entered student by student. It automatically calculates the total review marks and identifies the review status as **Completed, Partial, or Not Started**. The interface also supports keyboard-based navigation, enabling faculty members to enter marks efficiently. Review information is automatically saved to the Google Sheet, reducing manual record maintenance.

The **Dashboard Module** provides an overall summary of seminar activities through key performance indicators. Important statistics include the total number of groups, total students, allocated guides, unallocated groups, faculty engaged, groups reviewed, completed students, review marks entered, and groups having company information. The dashboard also provides visual representations of **faculty-wise review progress** and **domain-wise group distribution**, helping administrators quickly understand the current status of seminar activities.

The system further includes a **Faculty Master Module** for maintaining faculty records. Faculty members can be added or managed along with their Ph.D. status and maximum group allocation capacity. This information is used by the guide allocation mechanism to distribute seminar groups more systematically and to monitor faculty workload.

A dedicated **Company and Reports Module** is also incorporated into the system. It allows users to maintain company information associated with seminar groups and store company-letter references. The system supports Excel template download, Excel upload, data export, and PDF report generation. These features help in maintaining academic documentation and preparing reports for administrative and departmental requirements.

Overall, the **Seminar Guide Allocation and Review Dashboard** provides an integrated solution for managing postgraduate seminar activities. By combining group management, student information, automated guide allocation, faculty workload monitoring, student review assessment, company tracking, Google Sheet synchronization, Excel data handling, and report generation within a single platform, the system aims to reduce administrative workload, improve data consistency, increase transparency in guide allocation, and support effective monitoring of seminar progress.
